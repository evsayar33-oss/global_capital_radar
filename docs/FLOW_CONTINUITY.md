# Source-separated continuity
When ETFdb is unavailable, the primary row and its explicit error remain intact. The main daily report and Streamlit show a distinct continuity section with fresh ETFIQ historical or daily observations and first-seen USCF creation snapshots. No daily/weekly/monthly splicing; missing dates remain missing; the observed US session calendar must be fresh and latest source date may lag at most one observed session. ETFIQ start AUM is used only as a reported daily datum, not an independent normalization. USCF creation USD is a proxy (published net created shares times rounded NAV), not a historical backfill. QQQ rounded issuer snapshots never generate flows. No price trend gate and no promotion into primary decisions or evaluation. The original production error exit remains unchanged: observed alternative data is not a validated substitute for the primary strategy. Early-v1 outage observations are excluded from new recording and recalculation; immutable historical records are not deleted. The PR smoke simulates a primary outage and requires at least 8 actual alternative observations and 8 source-native histories. This is a regression floor, not all-source coverage or alpha proof. Historical PIT, COMEX, WTI, ALFRED, TBF3 and production method validation remain open.
