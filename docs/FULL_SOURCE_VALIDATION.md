# Isolated full source validation
The branch research/full-source-validation is isolated from main. Push-triggered tests use read-only contents permission, never send Telegram notifications, never push observations or deploy, and preserve evidence as Actions artifacts. The strict acceptance checks fresh current-run files, not previous successes. Each exact missing data target remains failed until real observations exist: COMEX, SHFE, actual TBF3 positions and settlement, exact ALFRED vintage and official WTI settlement. Treasury current and issuer WTI valuation cannot substitute. Daily history benchmark 400 consecutive sessions for each of the 12 ETFs, consistent with the existing nine complete ETFIQ series; this is a coverage benchmark, not alpha validation. All unit tests and actual main pipeline stages must pass. No merge or PR until strict gate passes; no change to strategy rules.
This initial branch adds a first-observed daily ETFIQ snapshot ledger sourced only from verified archived snapshot digests and live observations; separate from the fund-history endpoint, with previous-session checks, revisions and gap reporting. It preserves actual ALFRED vintages by content hash instead of overwriting them, and adds bounded SHFE retry for transient connection failures without retrying 403 or 429. Genuine historical gaps, exchange licensing and no-current-COT limitations remain unsolved. A failure in strict gate is evidence that a release is not ready, not a reason to weaken tests.
